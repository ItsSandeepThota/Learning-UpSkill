# Angular Frontend

This folder contains the Angular application for the UI layer.

Suggested structure:
- `src/app/core/` for singleton services, guards, and interceptors
- `src/app/shared/` for reusable components, pipes, and directives
- `src/app/features/` for feature modules or standalone feature areas
- `src/app/layouts/` for shell and page layouts
- `src/assets/` for static assets
- `src/environments/` for environment-specific settings
